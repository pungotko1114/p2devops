# Learning materials

Everything here is built around the Shortly stack in the repo root. Work through it in this order:

| Step | Material | What you do |
|---|---|---|
| 1 | [Docker capstone](docker-capstone.md) | Write the three Dockerfiles and `compose.yaml` yourself, in 11 steps, from blueprints and the official docs |
| 2 | [Git CLI lab guide](git-cli-lab-guide.md) | Six hands-on labs on a practice copy of Shortly: commits, undo, branches, remotes, rebase, guardrails |
| 3 | [Git Quest](git-quest/index.html) | A game with seven scenario-based shifts in a simulated terminal, ending in a 2 AM incident |

## Playing Git Quest

`git-quest/index.html` is a single self-contained page. GitHub shows its source rather than running it, so either:

- **Locally:** clone the repo and open `learn/git-quest/index.html` in a browser, or
- **GitHub Pages:** Settings → Pages → deploy from branch `main`, folder `/ (root)`, then open `https://<user>.github.io/shortly/learn/git-quest/`.

Progress is saved in your browser only. Fonts load from Google Fonts; offline it falls back to system fonts.
